# Python Expense Tracker

A practical command-line personal expense tracker.

## Features
- Add expenses with amount, category and description
- List expenses (filter by month or category)
- Monthly / overall category summary
- Export to CSV
- Delete entries
- Data saved in `expenses.json`

## Requirements
Python 3.7+

## How to run
```bash
python expense.py
```

## Example session
```
> add 12.50 food Lunch with friends
✓ Added: $12.50 in 'food'
> add 45.00 transport Uber to airport
> list
> summary
> export september.csv
> help
```
